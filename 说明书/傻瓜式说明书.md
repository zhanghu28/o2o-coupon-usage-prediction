# O2O 优惠券核销预测 · 傻瓜式说明书

> 这份说明书只解决一件事：**让你在自己的 Windows 电脑上，把这个项目从头到尾跑出来，并且知道每一步在干嘛。**
> 原理讲解看 `论文/小论文.md`，这份只管“手怎么动”。

---

## 0. 先搞清楚：这个项目到底是什么

一句话：**给一堆“某人某天领了一张优惠券”的记录，预测这个人 15 天内会不会用掉这张券。**

为什么这个预测值钱？商家发券要花钱（补贴）。如果能把券发给“大概率会用”的人，预算效率就高；
发给“必沉”的人，等于白送钱。我们要建的就是这个“谁会用”的筛选器。

比赛名字：天池 **O2O 优惠券使用预测**（2016 年）。
评分方式很特别：**不是整体 AUC，而是“每张券单独算 AUC，再把所有券的 AUC 平均”**。

|---|---|---|

## 3. 第二步：装 Python 库（只做一次，约 3 分钟）

### 3.1 打开 Anaconda 的命令行窗口

1. 点屏幕左下角 **开始菜单**（Windows 图标）
2. 在搜索框里输入 `anaconda`
3. 会看到**两个**长得像的图标，**两个都能用**，任选一个：
   - **Anaconda Prompt (anaconda3)**：黑底，光标前是 `(base) C:\Users\Redmi>`
   - **Anaconda PowerShell Prompt (anaconda3)**：蓝底，光标前是 `(base) PS C:\Users\Redmi>`
4. 记住你点开的是哪一个——下一步“切目录”两者的命令写法不一样。

### 3.2 进入项目文件夹

先看清你打开的是哪个窗口，**只粘对应的一条**，回车：

**① 黑底窗口（Anaconda Prompt，光标是 `(base) C:\Users\Redmi>`）**

```
cd /d D:\o2o_coupon_project
```

**② 蓝底窗口（Anaconda PowerShell Prompt，光标是 `(base) PS C:\Users\Redmi>`）**

```
cd D:\o2o_coupon_project
```

回车后核对光标：

| 窗口 | 成功的样子 |
|---|---|
| 黑底 CMD | `D:\o2o_coupon_project>` |
| 蓝底 PowerShell | `PS D:\o2o_coupon_project>` |

只要光标里出现 `o2o_coupon_project` 就算成功，接着做 3.3。

> **为什么不能通用**：`/d` 是 CMD 专用参数（用来顺便切换盘符），PowerShell 不认，
> 会报 `Set-Location: 找不到接受实际参数"D:\o2o_coupon_project"的位置形式参数`。
> 在 PowerShell 里直接 `cd D:\o2o_coupon_project` 就行，不要加 `/d`。

> 报“路径不存在”：先确认文件真的在 `D:\o2o_coupon_project`（资源管理器地址栏看一下），
> 不是的话把它剪切/解压到 D 盘根目录，再回来重执行这条命令。

### 3.3 安装依赖库

依次粘贴下面这一条，回车，等它跑完（会刷一堆进度条，正常）：

```
pip install -r requirements.txt
```

最后出现 `Successfully installed ...` 就成功。

> 报 `Could not find a version`：网络问题，先执行
> `pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple` 再重试。

### 3.4 检查装好了没

```
python -c "import pandas, sklearn, lightgbm, xgboost; print('全部OK')"
```

打印 `全部OK` 就过关。

## 7. 第六步：搞懂每个脚本在干吗（答辩会被问）

| 脚本 | 一句话 | 关键动作 |
|---|---|---|
| `src\config.py` | 参数总开关 | 改数据路径、时间切分、模型参数都只改这里 |
| `00_下载数据.py` | 下数据 | 从 ModelScope 拉 66MB CSV |
| `01_数据清洗.py` | 把脏数据洗干净 | ① 日期 `20160528.0` → 真日期；② `150:20` 拆成门槛/减免；③ 删 37,893 行重复；④ 校验消费不得早于领券；⑤ 按 15 天口径打标签 |
| `02_数据集成.py` | 1 张表 → 4 张画像表 | 用户/商家/券/用户×商家，再左连接成宽表 |
| `03_特征工程.py` | 造**只看过去**的特征 | “排序 → 累计求和 → shift(1)”实现 point-in-time；按 4/30 切训练/验证 |
| `04_模型训练.py` | 训 5 个模型并评分 | LR / LightGBM / XGBoost / HistGBDT / LGB分组感知；官方口径 = 按券分组算 AUC 再平均 |
| `05_预测与提交.py` | 出提交表 + 业务表 | 概率分 10 档，看每档真实核销率 |
| `06_可视化.py` | 出 12 张图 | 每张图的标题就是结论 |
| `07_生成结论报告.py` | 汇总 | 把 CSV 拼成一段结论文字 |

## 9. 常见报错对照表

| 报错关键词 | 原因 | 怎么办 |
|---|---|---|
| `'python' 不是内部或外部命令` | 没用 Anaconda 命令行 | 用 Anaconda Prompt 或 PowerShell Prompt，不要用系统 cmd |
| `Set-Location: 找不到接受实际参数` | PowerShell 里用了 `cd /d` | 去掉 `/d`，改成 `cd D:\o2o_coupon_project` |
| `系统找不到指定的路径` | `cd` 路径不对 | 核对文件夹真在 `D:\o2o_coupon_project` |
| `No module named 'lightgbm'` | 没装库 | `pip install lightgbm` |
| `FileNotFoundError ...csv` | 没下数据 | 先跑 `python src\00_下载数据.py` |
| 电脑很卡 / `MemoryError` | 内存不够 | 关掉浏览器和微信再跑 |
| Excel 打开乱码 | 编码问题 | 用“数据→从文本/CSV”并选 UTF-8 |
| 图表中文变方框 | 字体缺失 | 把 `src\config.py` 里字体候选第一项改成 `"Microsoft YaHei"` |
| `pip` 下载很慢 | 网络 | `pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple` |
| 第 5 步跑很久不动 | 模型在训练，正常 | 等 3-8 分钟，别按 Ctrl+C |
